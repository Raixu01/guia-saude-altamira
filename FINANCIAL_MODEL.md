## 1. Premissa Central: Utilidade Pública com Sustentabilidade

O **Guia de Saúde Altamira** tem como missão central o benefício público à população de Altamira-PA, garantindo acesso **100% gratuito e irrestrito para o cidadão comum**.

A sustentabilidade do projeto apoia-se em uma evolução em 3 fases:

```
┌────────────────────────────────────────────────────────┐
│  FASE 1: MVP Cidadão (Custo Zero / Free Tiers)         │
│  - Supabase Free + Vercel Free + Render Free           │
│  - Total: R$ 0,00/mês (+ R$ 40/ano de domínio)         │
└──────────────────────────┬─────────────────────────────┘
                           ▼
┌────────────────────────────────────────────────────────┐
│  FASE 2: B2B Clínicas Verificadas (Selo de Confiança)  │
│  - Clínicas pagam mensalidade opcional (R$ 49/mês)     │
│    para selo de verificação ativa, fotos e horários    │
│  - 5 a 10 clínicas parceiras cobrem 100% dos custos   │
└──────────────────────────┬─────────────────────────────┘
                           ▼
┌────────────────────────────────────────────────────────┐
│  FASE 3: Expansão Transamazônica (White-Label)         │
│  - Licenciamento para municípios vizinhos (R$ 500/mês) │
│    ou apoio institucional de cooperativas de saúde     │
└────────────────────────────────────────────────────────┘
```
